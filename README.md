# Manoel.ink

Site/portfólio do tatuador Juan Manoel ([@manoel.ink](https://www.instagram.com/manoel.ink/)) — Maceió/AL.

HTML, CSS e JS puros, sem build. O site fica em `manoel-ink/`; o conteúdo (trabalhos, cicatrizadas, flashes, WhatsApp) é editado no topo de `manoel-ink/script.js`.

Rodar local: `python -m http.server 5391 -d manoel-ink`
